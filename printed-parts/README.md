## Contents

- [custom-mods](custom-mods/) - custom Tinman-FP Rat Rig parts and assemblies.
- [rat-rig-official](rat-rig-official/) - V-Core 4.0 and 4.1 official printed-part sets and ZIP archives.
- [community-mods](community-mods/) - imported/community mod collections from the source folder.
- [reference-cad](reference-cad/) - vendor and reference geometry used for fit checks and design work.

Formats included: STL, STEP/STP, 3MF, F3D, PDF, ZIP, README, and license files.

Original upstream README and LICENSE files are preserved where they were present in the source folder.

## Git LFS

Most CAD, mesh, archive, and PDF assets in this directory are stored with Git LFS because several files are large, including the full Rat Rig V-Core 4.0 500 IDEX STEP assembly.

For a full clone:

```bash
git lfs install
git clone https://github.com/Tinman-FP/rat-rig-mods.git
cd rat-rig-mods
git lfs pull
```

## Safety

Review every part before printing. Check fitment, revision compatibility, material choice, chamber temperature, fastener clearances, and machine safety before installing anything on a live printer.
