# Community Mods

Imported or community mod collections preserved from the local Rat Rig source folder.

## Sections

- `enclosure/door-hinges-vcore-4/` - V-Core 4 door hinge and latch model files.
- `enclosure/archives/` - original archive for the door hinge model files.
- `lighting/v-core-led-daylight-mount/` - V-Core LED daylight mount files and related imported model files.

Preserved upstream PDFs, README files, and model files remain with their source collections.
