# Rat Rig Official Printed-Part Sets

Official Rat Rig V-Core printed-part sets preserved from the local source folder.

## Sections

- `v-core-4.0/printed-parts/` - V-Core 4.0 printed parts.
- `v-core-4.1-upgrade/printed-parts/` - V-Core 4.1 upgrade printed parts.
- `archives/` - original ZIP bundles from the source folder.

The original license files inside each printed-part set are preserved.
